# Quant Studio

面向 A 股与 ETF 的本地量化研究工作台。当前版本提供腾讯公开行情读取、分时/五日/日K/周K/月K切换、技术指标解释、自定义规则策略创建、创业板与科创50 ETF 策略回测和 OpenAI 兼容模型分析配置。公开行情仅用于研究验证，不保证交易级实时性。

## 启动

macOS 需要 Python 3.11+、Node.js 20+，首次启动会安装独立 Python/npm 依赖：

```bash
cd ~/Desktop/quant-studio
./start.sh
```

浏览器访问 <http://127.0.0.1:5173>。后端 API 文档在 <http://127.0.0.1:8765/docs>。

## 当前边界

- 首期行情源是腾讯公开行情，接口可能限流、延迟或不可用；没有券商级推送保证。
- 策略和回测仅用于研究，不会连接交易账户或提交订单。
- 创业板日K短线波段支持 159915、159977、159952、159957 和 159948：收盘突破前期高点、量能放大且站在 SMA60 上方时入场，跌破退出均线或 ATR 风险线时离场。
- 创业板 ETF 趋势风控支持 159915、159977、159952、159957 和 159948 日K：SMA200 显示牛熊背景；SMA60 执行中期趋势，连续两根收盘站上时入场，连续两根收盘低于 SMA60 时离场。显著反弹但未站稳中期趋势时标记为反弹观察。开仓及每月首个交易日按此前20根日K的年化波动率估算仓位，估算目标20%，上限100%，未用资金保留现金。盘中未完成日K不用于正式信号，信号和月度调整延后一根日K执行并计入交易成本，收益与买入持有同期对比。回测仅作研究，不能消除跳空和急跌，也不保证提高未来收益。
- 创业板底仓做 T 支持同一 ETF 范围，替代旧版现金开仓、日内清仓的模拟。境内股票 ETF 普通竞价交易实行 T+1；当前采用先卖已有旧份额、再买回，不能将当日买回份额反复卖出。
- 策略名称、模板默认值、规则预览与适用范围由后端策略模板目录统一提供，前端通过 `/api/strategy-templates` 读取。
- “新建策略”从空白规则开始，不选择或复制已有策略：设置标的、分钟/日/周/月周期，分别添加入场和离场条件，选择“全部满足”或“任一满足”。支持价格、成交量、SMA、EMA、RSI、ATR、区间高低点、均量与固定数值的比较或交叉，可配置周期、历史引用根数及乘数。
- 例如突破条件可配置为“收盘价 > 区间最高价(20)[前1根]”，放量条件可配置为“成交量 > 成交量均值(20)[前1根] × 1.5”。引用0代表信号K线，引用1排除信号K线自身。全部条件必须完成预热后才生成正式信号；新草稿的入场、离场条件均为空，必须填写后才能保存。
- 自定义规则独立保存，实时分析和回测使用同一规则计算器；仓位比例、最短持有根数、收盘确认的止损/止盈/跟踪回撤可配置。条件与风险退出在下一根开盘执行，风险退出不受最短持有期限制；入场与离场同时满足时不新开仓。分钟规则可设置完整交易日末按收盘价平仓，未完成交易日样本保留持仓。实时窗口不掌握实际持仓，只展示指标条件。
- 行情窗口仍可自由切换标的和周期；与规则配置不一致时只展示行情，明确提示策略信号不生效。自定义周/月规则不会在中间交易日收盘后提前确认当前周/月K线；交易所特殊节假日未接入，按日历工作周期保守确认。
- 已有三条内置策略继续独立保存和编辑原有参数。启动时载入最近保存的策略；保存修改更新同一条记录，无修改或正在保存时不重复提交。版本号表示修订次数，当前存储仅保留各策略的最新配置，不提供历史版本恢复。
- 修改标的、计算方法、参数或资金成本后清除旧回测结果；执行中的旧请求也不会覆盖新配置。
- 回测使用可用历史公开数据，采用下一根K线开盘执行，包含可配置手续费和滑点；当前还未覆盖涨跌停、分红税、市场冲击和幸存者偏差校正。
- AI API Key 保存在 macOS 系统钥匙串；服务地址和模型名存储在本地 `data/ai-settings.json`。

## 科创50 ETF：588080

实时分析中的当日盘中观察沿用通道策略参数，展示距突破上轨和退出下轨的幅度、趋势均线及其走升状态，以及各项尚未满足的入场条件。成交量口径为当日累计量 / 前20个完整交易日均量，不是同刻量比，未达到门槛不代表全天缩量；通道下轨也不是实际持仓ATR止损线。预热不足时明确提示，盘中观察不替代正式日K信号或成交记录。

研究脚本 `backend/research/star50_channel.py` 支持 `--saved-strategies data/strategies.json`，在同一日K快照和共同预热期内固定比较当前参数、跟踪2.5ATR/3ATR、趋势SMA150/SMA100，输出逐年、滚动12个月、成本敏感性和单笔盈利归因。研究报告不自动修改已保存策略，已观察过的历史比较不标为独立样本外验证。

当前保存的“科创50 ETF 趋势与量能确认通道”（`star50_channel`）实例为v9：跟踪止损2ATR、入场高点回看15日；SMA200须高于20日前以较早确认趋势，其余量能、风险预算和退出条件不变。最新1万元历史样本累计61.68%、年化8.66%、最大回撤-9.32%，比v8多交易并加入2024年一笔约-5.3%的失败交易；年化15%目标仍未达到。20日和30日走升确认周期在本样本触发相同交易，仍存在历史参数选择风险。图表现按策略显示SMA200、前15日高点和前10日低点。旧`star50_pullback`、`star50_breakout`仍是独立规则。

“科创50 ETF 趋势突破与ATR风控”是独立内置策略，默认参数为研究初值，不是收益优化结果。只支持588080日K：收盘高于SMA60且SMA60高于前5根时的均线，收盘突破此前20根高点，成交量不低于此前20根均量的1.2倍；两个参考窗口均排除信号K线。日K在15:00之前（包括午休）不用于正式信号。

下一可观测交易日开盘尝试一次入场。初始风险线为信号收盘减2.5倍信号日ATR20并冻结；开盘相对信号收盘的绝对偏离超过1倍信号ATR20、风险线无效、零成交量、已知不可成交或资金不足100份时取消，不顺延旧入场信号。按“策略资金×0.5%/开盘至风险线距离”计算份额，同时受50%开仓上限、可用现金和100份整数手约束，开仓上限不是固定仓位。

持仓以来最高已完成收盘价减3倍当前ATR20作为跟踪候选线，与原风险线取较高者，只上移不下调。收盘触及风险线，或连续两根收盘低于或等于各自SMA20，下一交易日尝试全部退出。T+1禁止当日卖出当日买入份额；无法退出时保留待退出状态，价格恢复也不取消待退出。退出优先，同一开盘不先卖后买；不摊平、不加仓、不设固定止盈，不每日自动调仓。费用、跳空和执行延迟可使损失超过0.5%的计划价格风险预算。

实时窗口没有账户持仓，只核验趋势、突破、量能和均线退出，不伪造实际持仓ATR风险线、份额或已执行交易。回测展示风险线轨迹、取消入场、待退出、成本、平均盈亏、换手、100%持有及50%持有加现金对照；成本场景重新计算份额和完整成交路径。2020—2023、2024、2025起的时间分段仅为回顾，不标为独立样本外验证。

价格和成交的边界：当前仍使用前复权OHLC，同一调整尺度内计算信号、风险线与模拟资金，尚未映射未复权成交价与分红现金流，因此100份和0.001元网格也是该价格尺度的研究近似，不能作为精确实盘账本。日K开盘不是可验证的盘口成交；零量或显式buyExecutable/sellExecutable=false的日K阻止对应成交，20%方向涨跌停开盘按调整后价格保守阻止，无法校验真实排队成交、盘中恢复流动性与缺失交易日。无可执行报价不模拟成交。

## AI 跨市场综合分析

实时分析与 AI 模型页共用一份报告。点击生成时，后端并发采集公开市场资料，再连同当前标的的历史结构、技术指标、策略参数及规则输出交给已配置的 OpenAI 兼容模型。报告覆盖美股与宏观传导、A股盘面与资金、近期核心事件、市场阶段及价格参考、板块与条件化应对、当前策略综合结论。仓位与节奏属于假设情景下的研究思路，不改变原策略或执行交易。

- 美股：Yahoo Finance 的道指、标普500、纳指、费半、VIX、10年期美债收益率、美元指数。日变化优先使用供应商最新报价相对昨收的口径，否则比较相邻可用日线；近5期使用5个有效日线间隔并保留起止日期。美债收益率变化用基点；美元指数为跨日连续报价，不强行当作美股收盘数据。
- A股：东方财富的四大指数、涨跌统计与成交额、近期已完成日线、行业涨跌排行及主力资金估算；腾讯提供四指数实际分钟采样路径。上证/深成接口统计范围不冒充严格全A，沪深合计不叠加创业板和科创50；盘中累计成交额不直接与全天成交额比较。
- 北向：当前未接入可核验的净买入披露，明确标记不可用；不将公开接口的额度或占位零值解释为实际资金流向。主力资金是供应商按成交单规模的估算，不是机构账户资金流。
- 事件：新浪财经、CNBC 与 Google News 公开资讯源，只选发布时间在最近7天内的可用条目并提供链接；不代表完整新闻库，标题摘要不单独证明因果关系。
- 价格参考：指数使用已完成日线；当前标的按当前图表K线周期计算。前5/20/60根高低点排除最新一根，均线包含最新一根；仅作为历史参照，不保证构成有效支撑或压力。

每项资料保留独立日期/更新时间，报告展示采集时间、生成时间、当前标的数据时间、来源编号和缺失项。完整市场快照缓存120秒，部分失败缓存30秒；单个源失败不补造数据，也不阻断其他可用资料。切换标的、周期或策略会清除旧报告，过期请求不会覆盖新配置。报告不包含实际账户持仓；模型服务会收到当前标的与策略摘要及公开市场/新闻资料。

DeepSeek V4 系列与 `deepseek-flash` 使用16000个输出 token 的预算和低推理强度，为推理及六部分正文预留空间；其他模型保留5000个 token 的预算。若模型返回了截断正文，页面保留内容并明确标记“未完成”；没有正文时仍报告失败，不将推理内容作为分析结果展示。

## 底仓做 T

回测“初始账户权益”包含期初已有底仓市值和现金，不是额外投入资金。默认底仓占权益 50%，单次最多卖出初始底仓的 50%；均按 100 份取整，资金不足一个交易单位时明确报错。起始底仓假设上一交易日已持有，按首个采样价估值，未模拟期初建仓费用。

卖出观察使用当日 EMA/VWAP/ATR：快线连续两根低于慢线、快线及价格回落，同时价格对 VWAP 的溢价覆盖 ATR 倍数、双边成本和两个最小变动单位（取最大值）。只响应一次新条件，下一分钟有报价时执行，执行价若已失去溢价则取消该次卖出。14:45 后不再新增卖出。

“做T决策周期”可选 1、5、15 分钟，默认保留 1 分钟。实时分析顶部可直接切换，策略研究页也可编辑并保存，回测使用相同参数；行情图周期仍独立切换。5/15 分钟K线由原始分钟样本按上午9:30、下午13:00对齐合成，不跨午休或交易日；缺失分钟或未完成区间不合成。确认收盘后才可在下一分钟报价成交，保护买回仍逐分钟检查，14:55恢复规则不变。“买回等待根数”按所选决策周期的完整K线根数计数。

5/15 分钟 EMA、ATR 使用最近可用的前序交易日决策K线连续预热，VWAP按原始分钟量价加权、每天重新累计；1分钟保留原有按日预热规则。15分钟一天约16根K线，因此EMA21、ATR20需要前序交易日数据；样本不足时明确显示“数据不足”。切换到日/周/月或五日图时只浏览行情，并提示策略基于所选分钟周期、当前不生效。不同周期沿用同一价差门槛，可能没有成交，不能把周期变长直接等同于收益提高。

卖出后，回落价差达到卖出时冻结的门槛、价格在 VWAP 下方企稳且等待根数满足时观察买回；上涨超过冻结门槛时优先保护买回，不受等待根数限制。14:55 起尝试恢复旧底仓，按实际可用现金买入整数手，不透支；缺少报价时不虚构成交。未完成买回部分按最新价计入相对持有的机会损益，下一交易日首个报价继续尝试恢复。

账本分别记录可卖旧份额、当天买回锁定份额和现金；午休不解锁，下一观察到的交易日才解锁。底仓保留隔夜风险。回测使用最近可获取的五日分时数据，并分列账户收益、同等初始底仓持有收益、做 T 增量（包含待买回盯市损益）、已配对净盈亏和成本。图表标注真实顺序的卖出、买回，未完成配对的成交也会标记。旧记录 ID 和自定义名称保持，默认旧名称及规则文案在读取时适配，不批量改写保存文件。

实时分析与回测共用价格条件；实时分析剔除尚未完成的最后一分钟，并使用回测表单当前的手续费/滑点预算。实时窗口没有用户持仓、可卖份额及上次卖出价，仅显示观察条件，不能视为实际交易指令。

腾讯分时是逐分钟采样价，不是完整分钟 OHLC；VWAP/ATR 与下一分钟开盘价均为近似。当前样本覆盖天数会显示，短样本不计算年化和夏普，也不能证明稳定超额。手续费/滑点按比例估算，未覆盖最低佣金、盘口价差、涨跌停或市场冲击。成本敏感性会按对应成本重新计算价差门槛，成交路径可能随之变化。
