# Quant Studio

面向 A 股与 ETF 的本地量化研究工作台。当前版本提供腾讯公开行情读取、分时/五日/日K/周K/月K切换、技术指标解释、自定义规则策略创建、三种已有创业板 ETF 策略与规则策略回测和 OpenAI 兼容模型分析配置。公开行情仅用于研究验证，不保证交易级实时性。

## 启动

macOS 需要 Python 3.11+、Node.js 20+，首次启动会安装独立 Python/npm 依赖：

```bash
cd ~/Desktop/quant-studio
./start.sh
```

浏览器访问 <http://127.0.0.1:5173>。后端 API 文档在 <http://127.0.0.1:8765/docs>。

## 当前边界

- 首期行情源是腾讯公开行情，接口可能限流、延迟或不可用；没有券商级推送保证。
- 策略和回测仅用于研究，不会连接交易账户或提交订单。
- 创业板日K短线波段支持 159915、159977、159952、159957 和 159948：收盘突破前期高点、量能放大且站在 SMA60 上方时入场，跌破退出均线或 ATR 风险线时离场。
- 创业板 ETF 趋势风控支持 159915、159977、159952、159957 和 159948 日K：SMA200 显示牛熊背景；SMA60 执行中期趋势，连续两根收盘站上时入场，连续两根收盘低于 SMA60 时离场。显著反弹但未站稳中期趋势时标记为反弹观察。开仓及每月首个交易日按此前20根日K的年化波动率估算仓位，估算目标20%，上限100%，未用资金保留现金。盘中未完成日K不用于正式信号，信号和月度调整延后一根日K执行并计入交易成本，收益与买入持有同期对比。回测仅作研究，不能消除跳空和急跌，也不保证提高未来收益。
- 分钟级日内交易支持同一创业板 ETF 范围，使用 EMA 与当日 VWAP 条件，完整交易日结束时强制平仓，盘中样本保留持仓；腾讯公开分钟数据仅覆盖短期，不能据此评估长期收益、回撤或夏普。
- 策略名称、模板默认值、规则预览与适用范围由后端策略模板目录统一提供，前端通过 `/api/strategy-templates` 读取。
- “新建策略”从空白规则开始，不选择或复制已有策略：设置标的、分钟/日/周/月周期，分别添加入场和离场条件，选择“全部满足”或“任一满足”。支持价格、成交量、SMA、EMA、RSI、ATR、区间高低点、均量与固定数值的比较或交叉，可配置周期、历史引用根数及乘数。
- 例如突破条件可配置为“收盘价 > 区间最高价(20)[前1根]”，放量条件可配置为“成交量 > 成交量均值(20)[前1根] × 1.5”。引用0代表信号K线，引用1排除信号K线自身。全部条件必须完成预热后才生成正式信号；新草稿的入场、离场条件均为空，必须填写后才能保存。
- 自定义规则独立保存，实时分析和回测使用同一规则计算器；仓位比例、最短持有根数、收盘确认的止损/止盈/跟踪回撤可配置。条件与风险退出在下一根开盘执行，风险退出不受最短持有期限制；入场与离场同时满足时不新开仓。分钟规则可设置完整交易日末按收盘价平仓，未完成交易日样本保留持仓。实时窗口不掌握实际持仓，只展示指标条件。
- 行情窗口仍可自由切换标的和周期；与规则配置不一致时只展示行情，明确提示策略信号不生效。自定义周/月规则不会在中间交易日收盘后提前确认当前周/月K线；交易所特殊节假日未接入，按日历工作周期保守确认。
- 已有三条内置策略继续独立保存和编辑原有参数。启动时载入最近保存的策略；保存修改更新同一条记录，无修改或正在保存时不重复提交。版本号表示修订次数，当前存储仅保留各策略的最新配置，不提供历史版本恢复。
- 修改标的、计算方法、参数或资金成本后清除旧回测结果；执行中的旧请求也不会覆盖新配置。
- 回测使用可用历史公开数据，采用下一根K线开盘执行，包含可配置手续费和滑点；当前还未覆盖涨跌停、分红税、市场冲击和幸存者偏差校正。
- AI API Key 保存在 macOS 系统钥匙串；服务地址和模型名存储在本地 `data/ai-settings.json`。
